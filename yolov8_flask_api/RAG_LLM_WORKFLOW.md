## 詳細流程說明

### 步驟 1: 接收使用者問題

```python
# 範例
query = "雞肉的營養成分有哪些？"
answer = rag_service_chroma.generate_answer_with_rag(query, k=3)
```

**參數說明**:
- `query`: 使用者的問題
- `k`: 從向量資料庫檢索的文檔數量（預設 3）

---

### 步驟 2: 向量相似度搜尋

```python
# 在 rag_service_chroma.py 中
query_docs = self.similarity_search(query, k=3)
```

**技術細節**:
1. **嵌入模型**: `paraphrase-multilingual-MiniLM-L12-v2`
   - 384 維向量
   - 支援多語言（中文、英文）
   - CPU 運算

2. **向量資料庫**: ChromaDB
   - 持久化儲存（knowledge-base/）
   - 相似度度量: cosine
   - 資料筆數: 2,503 筆

3. **搜尋結果**:
   - 返回最相關的 k 個文檔
   - 每個文檔包含：
     - `page_content`: 文本內容
     - `metadata`: 食物名稱、營養數據等

---

### 步驟 3A: RAG 模式（找到文檔）

**條件**: `if query_docs and len(query_docs) > 0`

**提示詞結構**:
```python
prompt_text = """你是一位專業的營養師，你的目標是幫助使用者了解營養知識並提供健康的飲食建議。

你需要使用專業且友善的語氣，並以清晰易懂的方式解釋營養相關問題。

回答問題時要直接且實用，不須提到「根據所提供的資料」。

請依所提供的營養知識（下文）進行回答，若無法回答問題，請直接回覆：抱歉！我無法回答您這個問題，建議您諮詢專業營養師。

=========
{documents}  # ← 從向量資料庫檢索到的文檔
=========

回答下列問題：
{question}   # ← 使用者的問題
```

**範例**:
```
輸入: "雞肉的營養成分有哪些？"

檢索到的文檔:
- 肉雞: 蛋白質 18.5g, 脂肪 10.2g, 熱量 190 kcal...
- 烏骨雞: 蛋白質 22.0g, 脂肪 5.5g, 熱量 146 kcal...

最終提示詞:
"...請依所提供的營養知識（肉雞: 蛋白質 18.5g...）進行回答：雞肉的營養成分有哪些？"
```

---

### 步驟 3B: Fallback 模式（找不到文檔）

**條件**: `if not query_docs or len(query_docs) == 0`

**提示詞結構**:
```python
fallback_prompt = """你是一位專業的營養師，你的目標是幫助使用者了解營養知識並提供健康的飲食建議。

你需要使用專業且友善的語氣，並以清晰易懂的方式解釋營養相關問題。

請使用你的專業知識回答以下問題。如果問題超出營養學範疇，請禮貌地說明並建議相關的專業資源。

回答下列問題：
{question}   # ← 直接問題，無資料庫上下文
```

**範例**:
```
輸入: "什麼是生酮飲食？"

向量資料庫: 找不到相關文檔

最終提示詞:
"...請使用你的專業知識回答以下問題：什麼是生酮飲食？"
```

**日誌記錄**:
```python
logger.info(f"向量資料庫中找不到相關資訊，使用 LLM 自身知識庫回答: {query}")
```

---

### 步驟 4: LLM Manager

**位置**: `services/llm_provider.py`

**主要方法**:
```python
result = self.llm_manager.generate_with_translation(
    final_prompt,
    context="營養建議",
    temperature=0.7,
    max_tokens=2048
)
```

**返回格式**:
```python
{
    'text': '生成的回答文本',
    'provider': 'GEMINI',  # 使用的提供者
    'translated': False,   # 是否經過翻譯
    'translator': None,    # 翻譯器名稱（如有）
    'error': None          # 錯誤訊息（如有）
}
```

---

### 步驟 5: LLM 提供者選擇與備援

**提供者列表** (按優先順序):

1. **Gemini API** (優先)
   ```python
   Provider: GEMINI
   Model: gemini-2.0-flash-exp
   API Key: GEMINI_API_KEY (環境變數)

   特性:
   - 實驗性最新模型
   - 支援繁體中文
   - 30 秒超時
   - 最多重試 2 次
   ```

2. **LM Studio** (備援)
   ```python
   Provider: LM_STUDIO
   Model: gemma-3-4b-it (Google Gemma 3, 4B 參數，指令微調版)
   Base URL: http://127.0.0.1:1234

   特性:
   - 本地運行（無需網路）
   - 快速回應
   - 無 API 成本
   - 60 秒超時
   - 支援對話和指令遵循
   ```

**備援邏輯**:
```python
for provider in [gemini, lm_studio]:
    if provider.is_available():
        result = provider.generate_content(prompt)
        if result:
            return result  # 成功，返回結果
        else:
            # 失敗，嘗試下一個提供者
            logger.warning(f"{provider.name} 失敗，切換到備援...")

# 所有提供者都失敗
return {'error': '所有 LLM 服務都不可用'}
```

### 步驟 6-7: 翻譯檢查與處理

**何時需要翻譯？**
1. LLM 返回的是簡體中文
2. LLM 返回的是英文或其他語言

**翻譯服務** (`services/translation_service.py`):

```python
翻譯器 1: Google Translate (優先)
- 免費
- 快速
- 支援多語言

翻譯器 2: Gemini API (備援)
- 使用 LLM 翻譯
- 品質較高
- 理解上下文
```

**翻譯流程**:
```
LLM 回應 (簡體中文)
    ↓
檢測語言 (langdetect)
    ↓
需要翻譯 → Google Translate
    ↓ (失敗)
Gemini API 備援翻譯
    ↓
繁體中文回答
```

### 使用場景對比

| 場景 | 範例問題 | 使用模式 | 資料來源 |
|------|---------|---------|---------|
| **資料庫內** | "雞肉的蛋白質含量？" | RAG 模式 | 向量資料庫 + LLM |
| **資料庫內** | "白飯的熱量是多少？" | RAG 模式 | 向量資料庫 + LLM |
| **一般知識** | "什麼是生酮飲食？" | Fallback | 純 LLM 知識 |
| **一般知識** | "如何計算 BMI？" | Fallback | 純 LLM 知識 |
| **資料庫外** | "間歇性斷食的好處？" | Fallback | 純 LLM 知識 |

## LLM 備援機制

### 備援流程圖

```
嘗試 Gemini API
    │
    ├─ 成功 ✅ → 返回結果
    │
    ├─ 失敗 ❌
    │   ↓
    │   logger.warning("Gemini 失敗，切換到備援...")
    │   ↓
    └─→ 嘗試 LM Studio
        │
        ├─ 成功 ✅ → 返回結果
        │
        └─ 失敗 ❌ → 返回錯誤
            "所有 LLM 服務都不可用"
```

### 失敗處理

**Gemini API 失敗原因**:
- API Key 無效
- 網路連接問題
- 超時（>30 秒）
- API 配額用盡
- 503 Service Unavailable

**處理方式**:
```python
# 在 llm_provider.py 中
try:
    response = self.model.generate_content(prompt)
    return response.text
except Exception as e:
    logger.error(f"Gemini API 失敗: {e}")
    self.is_available = False  # 標記為不可用
    return None
```

## 完整範例

### 範例 1: 資料庫內問題（RAG 模式）

**輸入**:
```
query = "雞肉的營養成分有哪些？"
```

**流程**:
```
1. 相似度搜尋
   → 找到 3 個文檔（肉雞、烏骨雞、雞睪丸）

2. RAG 模式
   → 組合提示詞（包含檢索到的營養數據）

3. LLM Manager
   → 使用 Gemini API 生成

4. 檢查語言
   → 已是繁體中文，不需翻譯

5. 返回結果
```

**輸出**:
```
"雞肉富含優質蛋白質，每100克約含18-22克蛋白質。
以肉雞為例，每100克含有蛋白質18.5克、脂肪10.2克、熱量約190大卡。
雞肉也含有豐富的維生素B群、磷、鐵等營養素..."
```

---

### 範例 2: 資料庫外問題（Fallback 模式）

**輸入**:
```
query = "什麼是生酮飲食？"
```

**流程**:
```
1. 相似度搜尋
   → 找不到相關文檔（或相關性太低）

2. Fallback 模式
   → 使用簡化提示詞（不包含資料庫上下文）
   → 日誌: "向量資料庫中找不到相關資訊，使用 LLM 自身知識庫回答"

3. LLM Manager
   → 使用 LM Studio 生成（Gemini 失敗時）

4. 檢查語言
   → 已是繁體中文，不需翻譯

5. 返回結果
```

**輸出**:
```
"生酮飲食是一種特殊的飲食方式，主要目標是讓身體進入酮體生成狀態。
當碳水化合物攝取量大幅減少（通常低於50克），而脂肪攝取量增加時，
身體會分解脂肪產生酮體作為能量來源..."
```
