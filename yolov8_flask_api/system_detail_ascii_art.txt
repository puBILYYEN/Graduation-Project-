  問題 1: Docker 映像過大
  ═══════════════════════════════════════════════════════════════════════

  映像大小分解:
  ├─ Base Image (python:3.12-slim)         : ~150 MB
  ├─ 系統依賴 (OpenCV, libgl1, etc.)        : ~200 MB
  ├─ PyTorch + torchvision                 : ~800 MB
  ├─ YOLOv8 模型檔案                        : ~100 MB
  ├─ Langchain + ChromaDB + 依賴            : ~300 MB
  ├─ 其他 Python 套件                       : ~200 MB
  └─ 應用程式碼                             : ~10 MB
     ─────────────────────────────────────────────
     總計 (未壓縮)                          : ~1.76 GB
     總計 (壓縮後)                          : ~700 MB

     拉取時間估算:
     • 網路頻寬: 50 Mbps
     • 預估下載時間: 700 MB / 50 Mbps ≈ 112 秒 (約 2 分鐘)
     • 解壓縮時間: ~1 分鐘
     • 總計: ~3 分鐘

     但實際上：
     • Cloud Run 映像拉取有嚴格超時限制
     • 大型映像經常超時失敗

  問題 2: 冷啟動開銷
  ═══════════════════════════════════════════════════════════════════════

  冷啟動時間分解:
  ├─ 映像拉取                               : ~120 秒 (如果成功)
  ├─ 容器啟動                               : ~2 秒
  ├─ Python 導入 torch 等套件                : ~5 秒
  ├─ GCS 下載向量資料庫                      : ~3 秒
  ├─ 載入 Chroma 向量資料庫                  : ~2 秒
  ├─ 初始化 Firebase                        : ~1 秒
  └─ 載入 YOLOv8 模型                        : ~3 秒
     ─────────────────────────────────────────────
     總計                                    : ~136 秒 (2 分 16 秒)

     Cloud Run 健康檢查超時: ~10 分鐘
     但映像拉取本身可能失敗！

  ═══════════════════════════════════════════════════════════════════════

  當前配置:
  ├─ CPU: 2 cores (啟動時無 boost)
