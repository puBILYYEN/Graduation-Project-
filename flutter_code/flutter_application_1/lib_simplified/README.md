### 📱 使用方法

1. 將 `lib_simplified` 目錄複製到你的 Flutter 專案
2. 修改 `pubspec.yaml` 中的 main 入口：
   ```yaml
   flutter:
     main: lib_simplified/main_ak47.dart
   ```
3. 執行應用程式：
   ```bash
   flutter run
   ```
