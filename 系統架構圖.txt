================================================================================
                            功能模組詳解
================================================================================

1. 身份驗證模組
   功能:
     • 使用者註冊/登入
     • Google OAuth 整合
     • 個人資料設定
     • 自動登入（靜默登入）

   技術:
     • Firebase Authentication
     • Google Sign-In SDK
     • 安全權杖管理

   資料流:
     登入頁面 → AuthRepository → FirebaseAuthDatasource → Firebase Auth


2. 相機與 AI 分析模組
   功能:
     • 即時相機預覽
     • 照片拍攝
     • 閃光燈控制
     • 前後鏡頭切換
     • 從相簿選取圖片
     • AI 食物辨識
     • 營養分析

   技術:
     • Camera Plugin
     • Image Picker
     • YoloV8 API
     • Gemini AI
     • 裝置方向感應器

   資料流:
     相機畫面 → 拍照 → YoloAPI → Flask 後端 →
     YoloV8 偵測 → Gemini 分析 → RAG 個人化 → 顯示結果


3. 飲食日記模組
   功能:
     • 新增/編輯/刪除餐點記錄
     • 依日期瀏覽記錄
     • 餐點類型分類（早/午/晚/點心）
     • 完整營養資訊顯示
     • 照片瀏覽

   技術:
     • Firestore 即時同步
     • Firebase Storage（圖片）
     • 日期過濾
     • CRUD 操作


4. 統計圖表模組
   功能:
     • 每日營養攝取統計

================================================================================
                            RAG 系統架構
================================================================================

┌─────────────────────────────────────────────────────────────┐
│              RAG (檢索增強生成) 系統                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 知識庫建立                                              │
│     ├─ 營養資料庫（台灣食品營養成分）                       │
│     ├─ 健康指南文件                                         │
│     └─ 使用者歷史記錄                                       │
│                                                             │
│  2. 向量化                                                  │
│     ├─ Sentence Transformers                                │
│     ├─ 將文字轉換為向量                                     │
│     └─ 儲存至 ChromaDB                                      │
│                                                             │
│  3. 查詢處理                                                │
│     ├─ 使用者問題 → 向量化                                  │
│     ├─ 相似度搜尋（向量資料庫）                             │
│     └─ 取回相關文件                                         │
│                                                             │
│  4. 生成回答                                                │
│     ├─ 結合查詢結果 + 使用者上下文                          │
│     ├─ 透過 Langchain 組織提示詞                            │
│     ├─ Gemini AI 生成個人化回答                             │
│     └─ 回傳給使用者                                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘

範例對話:
  使用者: "我今天吃太多了嗎？"

  RAG 流程:
  1. 查詢使用者今日攝取記錄（Firestore）
  2. 搜尋營養建議（ChromaDB）
  3. 計算攝取量 vs 建議量
  4. Gemini 生成個人化回答:
     "您今天攝取了 1850 大卡，根據您的身高體重，
      建議攝取 1600-1800 大卡。建議晚餐減少澱粉..."
