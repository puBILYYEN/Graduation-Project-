================================================================================
                    AI 助理回應系統 - 詳細流程圖
================================================================================

## 系統概述

AI 助理系統整合了三個核心 AI 技術：
1. YoloV8 - 食物影像辨識
2. Gemini 1.5 Flash - 營養分析與對話
3. RAG (檢索增強生成) - 個人化建議

================================================================================
                    錯誤處理與容錯機制
================================================================================

┌─────────────────────────────────────────────────────────────────────────┐
│                          錯誤場景處理                                    │
└─────────────────────────────────────────────────────────────────────────┘

場景 1：YoloV8 偵測失敗
┌──────────────────────────────────┐
│  原因：                          │
│  • 圖片模糊                      │
│  • 無法辨識的物體                │
│  • 圖片格式錯誤                  │
└────────┬─────────────────────────┘
         │
         ▼
┌──────────────────────────────────┐
│  處理：                          │
│  1. 回傳空的 predictions 陣列    │
│  2. Gemini 提供通用建議          │
│  3. 建議使用者重新拍攝            │
└──────────────────────────────────┘

場景 2：Gemini API 超時
┌──────────────────────────────────┐
│  原因：                          │
│  • API 回應過慢 (>30秒)          │
│  • 網路問題                      │
│  • API 配額用盡                  │
└────────┬─────────────────────────┘
         │
         ▼
┌──────────────────────────────────┐
│  處理：                          │
│  1. Retry 機制（最多 3 次）      │
│  2. 使用預設回應範本              │
│  3. 記錄錯誤日誌                  │
│  4. 通知前端降級服務              │
└──────────────────────────────────┘

場景 3：Firebase 資料取得失敗
┌──────────────────────────────────┐
│  原因：                          │
│  • 使用者無歷史資料              │
│  • Firebase 連線問題              │
│  • 權限不足                      │
└────────┬─────────────────────────┘
         │
         ▼
┌──────────────────────────────────┐
│  處理：                          │
│  1. 使用預設使用者資料            │
│  2. 提供通用建議（不個人化）      │
│  3. 提示使用者完善資料            │
└──────────────────────────────────┘

場景 4：RAG 檢索無結果
┌──────────────────────────────────┐
│  原因：                          │
│  • 問題超出知識庫範圍            │
│  • 向量資料庫未初始化            │
└────────┬─────────────────────────┘
         │
         ▼
┌──────────────────────────────────┐
│  處理：                          │
│  1. 直接使用 Gemini 回答          │
│  2. 不加入 RAG 知識               │
│  3. 記錄缺失的知識點              │
│  4. 後續更新知識庫                │
└──────────────────────────────────┘
